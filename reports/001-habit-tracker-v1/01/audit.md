## Замечания

Блокирующих дефектов в коде и тестах не найдено. BLOCKED вызван только невыполненным e2e.

1. **NOTE — потеря данных при работе в двух вкладках.** `src/main.js:28` (`let state = loadState(storage)`
   только при загрузке) и `main.js:64-69` (`commit` перезаписывает ключ целиком).
   Сценарий: открыть сайт в двух вкладках → во вкладке A добавить привычку «Вода» → во вкладке B
   отметить любую привычку → обновить A: «Вода» исчезла, потому что B записала своё устаревшее состояние.
   Последствие: тихая потеря привычек и отметок (затрагивает AC-8 в реальном использовании, e2e это не ловит).
   Исправление (минимальное): подписаться на `window.addEventListener('storage', e => { if (e.key === STORAGE_KEY) { state = loadState(storage); render(); } })`;
   либо перечитывать `state = loadState(storage)` в обработчике `focus`/`visibilitychange` перед `render()`.

2. **NOTE — e2e при повторном запуске может проверить устаревшую сборку.** `playwright.config.js`:
   `reuseExistingServer: !process.env.CI`. Если у пользователя уже запущен `npm run preview` на 4173
   (например, от старой сборки или от диагностики), Playwright не пересоберёт проект и протестирует
   старый `dist/`. Исправление для прогона: перед `npm run test:e2e` убедиться, что порт 4173 свободен
   (или запустить с `CI=1`), и записать это в новый validation.md.

3. **NOTE — e2e не проверяет наличие ✍️ в наборе эмодзи.** `tests/e2e/habits.spec.js:67`: список
   проверяемых символов содержит 11 эмодзи без `✍️`; общее число 12 проверяется (`:66`), а unit
   (`habits.test.js:28`) проверяет полный массив. Последствие небольшое: замена ✍️ на другой символ в UI
   прошла бы e2e. Исправление: добавить `'✍️'` в массив или проверять `data-emoji` у всех `emoji-option`
   против полного списка из GOAL.md.

4. **NOTE — отчётные логи не попадут в git.** `.gitignore` содержит `*.log`, поэтому `unit.log`, `e2e.log`,
   `build.log`, `webserver-diag.log`, на которые ссылается `validation.md`, не будут закоммичены вместе с
   отчётами (AGENTS.md: «Записывай фактические команды и результаты в … reports/»). Исправление: добавить
   исключение `!reports/**/*.log` в `.gitignore` или копировать итоговый вывод в `validation.md`.

5. **NOTE — после каждого действия теряется фокус клавиатуры.** `main.js:221` `listEl.replaceChildren(...)`
   пересоздаёт все кнопки; после нажатия Enter/Space на «Сегодня» или клетке сетки фокус уходит на `body`.
   Для учебной версии не критично; при желании сохранять `data-testid`/`data-date` фокусированного
   элемента и возвращать фокус после `render()`.

Отклонения от плана (эмодзи генерируются в JS, форма не перестраивается, вспомогательные экспорты
