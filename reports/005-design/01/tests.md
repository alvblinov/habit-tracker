## Сознательно не покрыто

- Внешний вид «мягкий минимализм» (скругления, тени, типографика, адаптивная вёрстка на ширине телефона),
  мягкость анимации — субъективно; остаётся для скриншотов координатора и ручной приёмки.
- Анимация `is-pop` и отключение при `prefers-reduced-motion` — не проверяются (в тестах кольца
  `reducedMotion: 'reduce'` используется только чтобы не читать стили посреди перехода).
- Отсутствие «вспышки» другой темы при загрузке — визуальный эффект, автоматически не измеряется
  (косвенно: сохранённая тёмная тема применяется сразу после загрузки).
- Заливка `meter` в строке статистики (псевдоэлементы `::-webkit-meter-*` недоступны через
  `getComputedStyle` элемента); цвет строки проверяется по её фону/рамкам/тени.
- Контраст второстепенного (muted) текста, баннеров и ошибок — AC-35 требует AA для основного текста.
- Недоступный `localStorage` (исключение при чтении темы) — в e2e не эмулируется.
- Конкретные HEX палитры — не фиксируются, проверяются различие и совпадение цветов.

## Допущения из плана (не из GOAL)

- Порядок «первый свободный» и «по кругу `index % 8`», позиция для старых данных — по итоговому списку
  (`plans/005-design.md`, раздел «Модель данных»); e2e/unit проверяют конкретные ключи (`purple`, `blue`, `pink`).
- `data-color` у `habit-card` и `stats-row`, `data-testid` `edit-color-option` (label с radio
  `value`/`aria-label`), `progress-ring` (`data-done`/`data-total`/`data-complete`), `progress-ring-label`,
  `theme-toggle` (`aria-label`/`aria-pressed`) — из плана.
