## Сознательно не покрыто

- `naturalWidth > 0` из плана заменено на более надёжную проверку загрузки: `img.decode()` разрешается, `img.complete`, ответ сервера `ok` с типом svg или webp, размер на странице больше 0. Причина: у SVG Noto, похоже, нет атрибутов `width`/`height` (только `viewBox`), а для таких картинок `naturalWidth` может быть 0 даже после успешной загрузки. Сам `naturalWidth` хелпер возвращает, но не проверяет.
- Само проигрывание кадров WebP и плавность «подпрыгивания» не проверяются: это визуальная оценка при ручной приёмке. Тесты проверяют, что выбран нужный файл, он загружен и CSS-анимация назначена.
- Точная длительность (ровно 2000 мс) не фиксируется: проверено «ещё идёт на 1 с» и «закончилось к 3 с», как требует «~2 с».
- Порядок слоёв внутри размытого фона и точные цвета пятен (палитра) не сравниваются с константами. Проверено, что пятна видны и различаются.
- Системные уведомления с символом эмодзи не перепроверялись: они не менялись, их покрывает `reminders.spec.js`.
- Контраст подписи в подвале (вторичный текст) не проверялся. AC-40 требует контраст основного текста.

## Что запустить

```
export PATH="/c/Program Files/nodejs:$PATH"
npm run test:unit                                  # 363 прежних + 72 новых в tests/unit/emoji-assets.test.js
npx playwright test tests/e2e/design.spec.js       # 19 прежних + 17 новых
npm run test:e2e                                   # полный прогон: 98 прежних + 17 новых
```

E2E собирает `dist/` (`npm run build` в `webServer`), поэтому в сборке должны оказаться `dist/emoji/*.svg|*.webp`.

Возможные места падения для анализа runner'ом:
- Проверка пикселей пятен в тёмной теме: порог 4 единицы канала. По расчёту для альфы 0.08–0.10 разница около 15.
- `clock.pauseAt(12:01)` должен быть позже момента загрузки страницы по управляемым часам (запас около 60 с реального времени).
