## Сознательно не покрыто

- Закрытие формы, когда привычку удалили в другой вкладке (storage-событие). Для этого нужны две страницы в одном
  контексте, а сценарий второстепенный для AC-19…AC-21. Ветка `render()` проверяется только косвенно.
- Восстановление позиции курсора при перерисовке: это не критерий приёмки, а деталь удобства.
- Внешний вид (вёрстка формы, адаптивность): автотестами не проверялся, остаётся для ручной приёмки.
- Режим напоминания «Каждые N» после переименования: имя подставляется в уведомление в момент срабатывания
  одинаково для обоих режимов, поэтому проверен только режим «в определённое время».
- Системное уведомление при запрещённых уведомлениях (плашка): прежнее поведение покрыто reminders.spec.js.
