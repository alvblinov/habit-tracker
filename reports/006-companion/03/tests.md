## Соответствие критериям

### AC-47: место помощника
- e2e «виджет fixed внизу справа…»: `position: fixed`; отступы персонажа от правого и нижнего края 8–40 px; страница прокручивается; после прокрутки к последней карточке персонаж в viewport и на том же месте (±1 px); `elementFromPoint` в центре персонажа попадает в персонажа.
- e2e «в самом низу страницы…»: при максимальной прокрутке персонаж не пересекается с «Сегодня», «Удалить», 🔔, ✏️ и клетками сегодня/вчера последней карточки (нижний отступ). Клик по клетке «сегодня» → `mark`; облачко пропускает клики (`elementFromPoint` в центре текста — не облачко); при видимом облачке клик по клетке вчера → `markPast` и «Удалить» → `deleted`.
- e2e «узкий экран 380×700»: персонаж и облачко полностью на экране, в правом нижнем углу.
- Прежние e2e других файлов не менялись; их прохождение — тоже проверка AC-47.

### AC-48: облачко
- e2e: заголовок — имя (`Рыжик`, затем `Квака`); «×» видна, доступное имя `/закрыть/i`, закрывает облачко; `data-accent` у лисы `orange`, у лягушки `green`; вычисленный цвет рамки у них разный и не прозрачный.
- e2e: печать на управляемых часах. Сразу: `data-full-text` и `aria-label` = полный ответ, `aria-busy="true"`, `textContent` пуст. Через 100 мс: 2–6 символов, начало текста. После `n × 25 мс`: текст полный, `aria-busy="false"`. Показ: видно при `печать + 4 с − 300 мс` (> 6 с, это проверено отдельно), скрыто через 600 мс.
- e2e при reduced motion: текст целиком без тиков часов, без `aria-busy`, `getAnimations({ subtree: true })` в виджете = 0; скрытие через 6 с (видно на 5.8 с, скрыто на 6.2 с).
- unit `ACCENTS`: 7 разных ключей; лиса — `orange`, лягушка — `green`; `accentOf` возвращает акцент кота для неизвестного id.

### AC-49: реплики на действия, вехи и конфетти
- unit: 20 поводов у всех персонажей. Название привычки есть в каждом варианте `added`, `firstHabit`, `markPast`, `milestone`, `reminderSet`, `edited`, `deleted`; у `milestone` есть серия 3/7/14/30/50/100 с правильным склонением.
- unit `companionEventForMark`:
  - вехи 3/7/14/30/50/100 → `milestone`; 2/4/6/8/13/15/29/31 — не веха;
  - веха важнее рекорда и «всё выполнено»; веха считается через смену месяца; пропуск дня обнуляет путь к вехе;
  - снятие отметки при серии-вехе → `unmark`; прошлый день, дотянувший серию до вехи → `milestone`; повторной вехи без роста серии нет (`markPast`);
  - прошлый день, давший рекорд → `newRecord`; `markPast` важнее `allDone`/`firstDayClosed`/`remaining`; прошлый месяц → `markPast`; снятие прошлого дня → `unmark`; не изменился день `date` → `null`;
  - `firstDayClosed` и `allDone` различаются по наличию раньше закрытого дня.
- unit `companionEventForAdd`: `firstHabit`/`added` с названием новой привычки; HTML передаётся как есть; без добавления → `null`; битые аргументы → `null`.
- e2e «на каждое действие»: первая привычка → `firstHabit`; следующая → `added`; «Сегодня» → `remaining`; клетка вчера → `markPast`; снятие → `unmark`; 🔔 сохранение → `reminderSet`; ✏️ название → `edited`; ✏️ дни недели → `edited`; удаление → `deleted`. Перед каждым шагом облачко закрывается «×», поэтому каждая реплика новая.
- e2e: первый закрытый день → `firstDayClosed`.
- e2e: вехи на засеянных данных. 3 — кнопкой «Сегодня», 7 — клеткой; реплика `milestone` с названием и «3 дня»/«7 дней»; 30–40 кусочков конфетти, контейнер `aria-hidden="true"`; через 2 с кусочков нет; обычная отметка — без конфетти.
- e2e при reduced motion: веха с той же репликой, конфетти нет.

### AC-50: «Спроси меня»
- unit: нормализация (регистр, ё→е, знаки, пробелы, HTML-теги как слова, не строка → ""); ≥ 40 записей, уникальные id, ответы без `{…}` и упрёков; совпадения по ключевым словам и синонимы («создать новую»); варианты одного вопроса с другим регистром, знаками и «ё» дают один ответ; незнакомые («ёжик», «qwerty», `<b>x</b>`, пусто) → `null`; 6–8 быстрых вопросов, у каждого есть запись; ответы всех персонажей на все записи содержат текст записи и не содержат `{…}`; стиль у персонажей разный; ответ на незнакомый вопрос свой у каждого и содержит «спроси».
- e2e: «Как ДОБАВИТЬ привычку???», «ТЁМНАЯ тема!!», «что такое серия», «забыл отметить вчера» → `data-event="answer"` и нужный `data-qa`, текст записи в ответе, поле очищено. Все быстрые кнопки по порядку: подписи совпадают, ответы точные. Незнакомый вопрос → `data-qa="unknown"` и ответ персонажа. Вопрос из пробелов — без ответа.
- e2e «HTML в вопросе»: `<img onerror>` и `<b>` в облачке не появляются, `window.__xss` не задан. Метки вопроса нет в localStorage, sessionStorage, адресе страницы, URL и теле запросов. Внешних запросов и ошибок страницы нет.

### AC-51: экскурсия
- unit: 6 шагов в порядке GOAL (форма, «Сегодня», сетка, 🔔, ✏️, статистика); тексты непустые; у шагов карточки есть `missingText`; цели есть в `index.html` или `src/main.js`.
- e2e (reduced motion, чтобы прокрутка была мгновенной): из меню 6 шагов; «Шаг N из 6», `data-step-id`, заголовок и текст шага; цель в viewport; подсветка (`companion-tour-spot`) охватывает цель; «Назад» недоступна на шаге 1 и работает с шага 3; на последнем шаге «Готово» закрывает.
- e2e: «Закрыть» и Esc закрывают экскурсию; после неё отметка работает.
- e2e без привычек: шаг 2 без подсветки (`data-has-target="false"`, spot скрыт), текст = `missingText`.
- e2e: после знакомства (лиса) после `intro` идёт `tourOffer` с кнопкой «Покажи!», `tourOffered: true`, кнопка запускает экскурсию. После reload предложения нет: журнал реплик через MutationObserver.

### AC-52: совет дня
- unit: ≥ 30 советов; `tipForDay` детерминирован; соседние дни (в том числе через смену месяца, года и 29.02) дают разные советы; за `TIPS.length` дней — все советы, затем повтор; некорректная дата не ломает. `shouldShowTip`: показ при `null`/вчера и после смены месяца; не показывается, если совет уже был сегодня, помощник выключен, знакомство не пройдено, настройки битые или дата некорректна.
- e2e: после приветствия идёт `tip` с `tipForDay(сегодня)`, `lastTipDate` = сегодня. Reload в тот же день — только `greeting`. Следующий день (`setSystemTime`) — снова `greeting` и `tip`, дата обновлена.
- e2e, локальная дата: в 00:30 МСК (в UTC ещё вчера) показывается совет нового дня, `lastTipDate` = новая дата. В 23:30 МСК того же дня совета нет.
- e2e: выключенный помощник — реплик нет, `lastTipDate` не меняется.

- Экскурсия при обычной (плавной) прокрутке: в e2e включён reduced motion, чтобы сверять подсветку с целью без гонки с реальной анимацией прокрутки.
- Предложение экскурсии тем, кто прошёл знакомство в прогонах 01–02: по реализации его нет, в GOAL это не уточнено.
- Отсутствие реплики при сохранении ✏️ без изменений: не требование.

Замечания для прогона:
