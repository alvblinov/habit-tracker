## Замечания

### BLOCKER 1 — противоречие в тесте `companion.spec.js:478` (дефект теста, не приложения)

- Место: `tests/e2e/companion.spec.js:127` (хелпер `expectBubble`: `expect(text).not.toMatch(/[{}]/)`) и тест `:478–490`.
- Проблема: тест задаёт название `<b>Жирный</b> {name}` и ожидает его дословно в облачке, а общий хелпер запрещает
  любые `{`/`}`. Фактический текст `«<b>Жирный</b> {name}» отмечено. Мурлычу от гордости за тебя.` — это ровно
  правильное поведение: `pickPhrase` подставляет значения одним проходом
  `template.replace(/\{(\w+)\}/g, …)` (`src/companion.js:588`), подставленное название повторно не разбирается,
  `{name}` из названия остался буквально и не заменился на «Барсик». В облачке текст выставлен через
  `textContent` (`src/main.js`, функция `say`). То есть приложение работает правильно, а тест сам себе противоречит.
- Последствие: e2e FAILED; ключевые для AC-44 проверки (`toContain(name)`, «нет дочерних элементов») в браузере
  не выполнялись.
- Исправление (без ослабления): дать хелперу ожидаемый буквальный фрагмент и проверять незаполненные
  плейсхолдеры в тексте *без* него, например:
  ```js
  async function expectBubble(page, event, { literal = null } = {}) {
    ...
    const rest = literal ? text.split(literal).join('') : text;
    expect(rest).not.toMatch(/[{}]/);
    return text;
  }
  // в тесте :486
  const text = await expectBubble(page, 'mark', { literal: name });
  expect(text).toContain(name);
  expect(text).not.toContain('Барсик'); // {name} из названия не подставлен повторно
  ```
  Остальные вызовы `expectBubble` не меняются. После правки — повторный `npm run test:e2e` (весь набор).

### NOTE 2 — совпадение реплики совы и пингвина на `remaining`

- Место: `src/companion.js:405` (owl) и `:459` (penguin): обе `'«{habit}» — есть. До закрытия дня — ещё {left}.'`.
  Других дословных совпадений между персонажами нет (проверено по `PHRASES`).
- Последствие: с вероятностью 1/3 сова и пингвин звучат одинаково и безлико — слабее требование AC-43
  «у разных персонажей реплики на один повод различаются стилем». Тон при этом корректный (без упрёков).
  Unit-тест `companion.test.js:204` такое пропускает: требует лишь хотя бы одну «свою» реплику.
- Исправление: дать обоим характерную реплику (сова — «Ух! «{habit}» — есть. По моим наблюдениям, ещё {left}.»,
  пингвин — «Есть «{habit}»! Лёд крепкий: до закрытия дня ещё {left}.») и в unit-тесте запретить дословные
  совпадения одной реплики у разных персонажей на один повод.
