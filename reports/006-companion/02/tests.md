## Что изменено

### BLOCKER 1 — `tests/e2e/companion.spec.js`

- Хелпер `expectBubble(page, event, { literal = null } = {})`: проверка на незаполненные `{`/`}`
  выполняется по тексту, из которого вырезан ожидаемый буквальный фрагмент
  (`text.split(literal).join('')`). Без `literal` поведение прежнее — весь текст без `{}`.
  Остальные проверки хелпера (видимость, `data-event`, непустой текст, нет упрёков) не изменены.
- Тест «HTML и «{name}» в названии выводятся как текст» (AC-44): вызов
  `expectBubble(page, 'mark', { literal: name })` и новая проверка
  `expect(text).not.toContain('Барсик')` — `{name}` из названия не подставлен повторно именем помощника
  (в тесте помощник переименован в «Барсик»). Проверки `toContain(name)`, нет `<b>` и нет дочерних
  элементов в облачке сохранены.
- Остальные вызовы `expectBubble` не менялись — для них строгая проверка `{}` по всему тексту осталась.

### NOTE 2 — `tests/unit/companion.test.js`

- Новый тест в `PHRASES — полнота и тон`: «у разных персонажей на один повод нет дословно совпадающих
  реплик» — для каждого из 10 поводов собирает реплики всех 7 персонажей и падает, если один и тот же
  шаблон (после `trim`) встречается у двух персонажей; сообщение называет повод, реплику и обоих персонажей.
  Прежний тест «наборы реплик различаются, у каждого есть свои» оставлен без изменений.
