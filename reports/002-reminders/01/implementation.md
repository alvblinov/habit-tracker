## Пункты плана

### Модель данных
`reminder: null | { mode: 'interval', intervalMin, start, end, anchor } | { mode: 'times', times }` — как в плане.

### `src/reminders.js`
- `normalizeReminder(raw)`: interval — `intervalMin ∈ INTERVALS`, `start`/`end` — `HH:MM` (00:00–23:59), `start < end`, `anchor` — конечное число; times — массив только валидных `HH:MM`, повторы убираются, сортировка, итог 1–5 (больше 5 уникальных → `null`). Любые лишние поля отбрасываются. Иначе `null`.
- `setReminder`: для interval `anchor = nowMs` (каждое сохранение перезапускает отсчёт); невалидный ввод или неизвестный id → то же самое состояние (`===`).
- `clearReminder`: `reminder = null`; неизвестный id или уже выключено → то же состояние.
- `describeReminder`: «каждый час, 9:00–21:00», «каждые 2 часа, …», «каждые 3 часа, …», «каждые 30 минут, …» (часы без ведущего нуля); times — «08:00, 20:00»; `null` → `''`.
- `findDueReminders`: моменты в `(fromMs, toMs]` и не раньше `toMs − graceMs` (по умолчанию 5 мин); не более одного на привычку (берётся самый поздний). interval — `anchor + k·interval`, k ≥ 1, местное время момента в `[start, end)`, отметка не учитывается. times — каждый день в HH:MM местного времени (`new Date(y, m, d, hh, mm)`), день с отметкой (`isDone(habit, dateKey)`) пропускается. `toMs <= fromMs` → `[]`. Циклы ограничены предохранителем 10 000 шагов.

### `src/main.js`
- Карточка: кнопка 🔔 `reminder-toggle` (между «Сегодня» и «Удалить»; `aria-expanded`, класс `is-active`, если напоминание включено); подпись `reminder-label` «🔔 <describeReminder>» под заголовком, только если напоминание есть.
- Панель `reminder-panel` внутри карточки (между кнопками и сеткой): радио `reminder-mode` (value `interval` — «Каждые N», `times` — «В определённое время»); для interval — `select` `reminder-interval` (value 30/60/120/180, подписи «30 минут», «1 час», «2 часа», «3 часа»), `input type=time` `reminder-start`, `reminder-end`; для times — поля `reminder-time` с кнопками «×» (`reminder-remove-time`, неактивна при одном времени) и «+ время» (`reminder-add-time`, неактивна при 5; добавляет следующий свободный ровный час после последнего); кнопки «Сохранить» (`reminder-save`), «Выключить» (`reminder-off`, только если напоминание уже включено), «Отмена» (`reminder-cancel`).
- Черновик по умолчанию: «Каждые N», 1 час, 09:00–21:00, для режима времён — `['09:00']`; при открытии панели для включённого напоминания черновик берётся из него.
- Открытая панель и черновик (`openReminderId`, `draft`) хранятся в памяти модуля; ввод обновляет черновик без перерисовки, структурные изменения (режим, добавить/удалить время) перерисовывают из черновика. Если привычку с открытой панелью удалили (в т.ч. в другой вкладке), панель закрывается.
- Ошибки сохранения — `reminder-error` (role=alert): «Начало активных часов должно быть раньше конца.», «Добавьте хотя бы одно время.», запасное «Проверьте настройки напоминания.».
- Сохранение: `ensurePermission()` вызывается в обработчике клика (действие пользователя), затем `setReminder(..., Date.now())` → `commit` (запись в localStorage + перерисовка), панель закрывается.
- Подсказка `reminder-hint` «Напоминания приходят, пока эта вкладка открыта» — на странице под строкой «Сегодня выполнено…», видна, если открыта панель или есть хотя бы одно напоминание.
- Планировщик: `lastCheck = Date.now()` при загрузке; `setInterval(checkReminders, 15000)`; `checkReminders()` также вызывается на `focus` и `visibilitychange` (после перечитывания состояния). Окно `(lastCheck, Date.now()]`, затем `lastCheck = now`. Если часы ушли назад — `lastCheck` сбрасывается без уведомлений.
- Показ: `showNotification({ title: '<эмодзи> Пора: <название>', tag: '<habitId>-<at>' })`; если вернуло `false` — плашка `reminder-banner` с текстом и кнопкой «Понятно» (`reminder-banner-close`). Несколько плашек — списком; для одной привычки держится одна плашка (новая заменяет старую). Весь пользовательский текст — через `textContent`.
- Фокус клавиатуры: `captureFocus` дополнительно различает радио по value; если элемент панели исчез (панель закрылась), фокус возвращается на 🔔 этой карточки.
