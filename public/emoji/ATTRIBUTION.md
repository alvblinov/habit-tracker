# Эмодзи

Картинки эмодзи — Google Noto Emoji, скачаны 14.10.2026 и хранятся локально
(сайт не загружает их из сети во время работы).

- `*.svg` — статичные эмодзи из [Noto Emoji](https://github.com/googlefonts/noto-emoji),
  изображения под лицензией Apache License 2.0.
  Источник: `https://fonts.gstatic.com/s/e/notoemoji/latest/<код>/emoji.svg`.
- `*.webp` — анимированные эмодзи из
  [Noto Emoji Animation](https://googlefonts.github.io/noto-emoji-animation/),
  лицензия Creative Commons Attribution 4.0 (CC BY 4.0), © Google.
  Источник: `https://fonts.gstatic.com/s/e/notoemoji/latest/<код>/512.webp`.
  Анимации нет у 🏃 (1f3c3), 🧘 (1f9d8), 💊 (1f48a) — для них только статичная картинка.

Имя файла — код символа в нижнем регистре (например, `1f4a7` — 💧, `270d_fe0f` — ✍️).
