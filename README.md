# Трекер привычек

Учебный проект курса «Вайбкодинг». Сайт, где любой человек без регистрации
добавляет привычки, отмечает их выполнение по дням и видит серию дней подряд
и сетку за 30 дней. Данные хранятся в браузере (localStorage).

Цель, первая версия и критерии приёмки — в [GOAL.md](GOAL.md),
текущее состояние — в [STATUS.md](STATUS.md).

## Стек

HTML/CSS, JavaScript, [Vite](https://vite.dev), [Vitest](https://vitest.dev)
для логики, [Playwright](https://playwright.dev) для браузерных тестов.

## Установка

Нужен Node.js 20+ (проверено на 24.20).

```bash
npm install
npx playwright install chromium
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер с перезагрузкой, http://localhost:5173 |
| `npm run build` | сборка в `dist/` |
| `npm run preview` | просмотр собранной версии |
| `npm run test:unit` | unit-тесты логики (Vitest, без watch), `tests/unit/` |
| `npm run test:e2e` | браузерные тесты (Playwright, Chromium), `tests/e2e/`; сам собирает и поднимает свежий сайт на порту 4173 (уже запущенный сервер не переиспользуется, порт должен быть свободен) |

## Публикация (GitHub Pages)

Сайт: https://alvblinov.github.io/habit-tracker/

Workflow `.github/workflows/deploy.yml` выполняет `npm ci`, `npm run test:unit`,
`npm run test:e2e` (Chromium) и `npm run build`:

- в каждом PR в `main` — только проверки (результат виден на странице PR);
- при push в `main` — проверки, затем публикация `dist/` на GitHub Pages.
  Если хоть один тест упал, сайт не обновляется; отчёт Playwright сохраняется
  в артефактах запуска (`playwright-report`).

В настройках репозитория: Pages → Source: GitHub Actions. Запустить вручную —
вкладка Actions → «Deploy to GitHub Pages» → Run workflow. Сборка использует
относительные пути (`base: './'` в `vite.config.js`), поэтому работает и в подпапке.

Каждый посетитель получает свой трекер: данные хранятся только в его браузере
(localStorage), аккаунтов и синхронизации между устройствами нет.

## Напоминания

Кнопка 🔔 на карточке привычки открывает настройки напоминания:

- «Каждые N» — каждые 30 минут / 1 / 2 / 3 часа в активные часы
  (по умолчанию 9:00–21:00), отсчёт от момента сохранения; приходит,
  даже если привычка уже отмечена сегодня;
- «В определённое время» — от 1 до 5 времён каждый день; не приходит,
  если привычка уже отмечена сегодня.

Ограничения:

- напоминания работают, **только пока вкладка с трекером открыта**
  (сервера нет); пропущенные, пока вкладка была закрыта, не досылаются;
- для системных уведомлений нужно разрешение браузера — его запрашивают
  при первом сохранении напоминания. Если уведомления запрещены или
  недоступны, напоминание показывается плашкой вверху страницы
  с кнопкой «Понятно».

## Расписание и статистика

- В форме ✏️ можно выбрать дни недели (Пн…Вс, хотя бы один). Выходные дни
  привычки в сетке бледнее, но отмечаются кликом; выходной без отметки не
  прерывает серию, отметка в выходной добавляет день. Напоминания приходят
  только в дни по расписанию. Привычки без расписания — «каждый день».
- Кнопка «📊 Статистика» вверху открывает блок с периодом 7 дней / 30 дней /
  всё время: процент выполнения по дням расписания, всего отметок, лучший день
  недели и таблица по привычкам. Неотмеченное сегодня процент не занижает.

## Оформление

- У каждой привычки свой цвет из палитры 8 цветов (бирюзовый, фиолетовый,
  коралловый, розовый, синий, зелёный, янтарный, серый). Новая привычка получает
  следующий свободный цвет; поменять его можно в форме ✏️. Старые данные без
  цвета открываются с цветами по порядку.
- Кольцо прогресса в шапке показывает «X/Y» выполненных сегодня привычек;
  когда выполнены все — кольцо зелёное.
- Тема: по умолчанию — как в системе; кнопка 🌙/☀️ в шапке переключает
  светлую/тёмную, выбор хранится в браузере под ключом `habit-tracker:theme`
  (данные привычек — отдельно, в `habit-tracker:v1`).
- Шрифт системный, ничего не загружается из сети; анимации отключаются
  при настройке «уменьшить движение».
- Эмодзи показываются картинками Google Noto из `public/emoji/` (12 статичных
  SVG и 9 анимированных WebP, хранятся в проекте, из сети не загружаются).
  В данных эмодзи по-прежнему символ Unicode; пути — в `src/emoji-assets.js`.
- На карточках привычек эмодзи анимированы постоянно (анимация Noto, WebP;
  у 🏃 🧘 💊 анимации нет — статичная картинка). В форме добавления, форме ✏️
  и статистике эмодзи статичные (SVG).
- При отметке сегодняшнего дня (кнопка «Сегодня» или клетка сегодня) эмодзи
  на карточке коротко «подпрыгивает» (~0,6 с). Снятие отметки и отметка
  прошлых дней эффекта не дают. При настройке «уменьшить движение» все эмодзи
  статичные и эффекта нет.
- Фон — неподвижные размытые пастельные пятна (бирюзовое, фиолетовое,
  коралловое), в тёмной теме приглушённые; карточки непрозрачные.
- Авторство: эмодзи Google Noto — изображения Noto Emoji (Apache 2.0)
  и анимации Noto Emoji Animation (CC BY 4.0); подпись со ссылкой — в подвале
  сайта, подробности — `public/emoji/ATTRIBUTION.md`.

## Помощник

- Помощник — один из 7 персонажей (анимированные эмодзи Google Noto):
  🐱 кот Мурзик, 🦊 лиса Алиса, 🐼 панда Пандуша, 🐸 лягушка Квака,
  🦉 сова Софа, 🐧 пингвин Пин, 🦔 ёжик Колючка. Он «живёт» в правом нижнем
  углу экрана и виден при прокрутке; у страницы есть нижний отступ, чтобы
  последние карточки можно было прокрутить выше него. При настройке «уменьшить
  движение» картинка статичная.
- При первом открытии (и один раз для тех, кто уже пользовался трекером) над
  формой добавления появляется карточка знакомства с выбором персонажа; она не
  закрывает страницу. «Позже» — помощником становится Мурзик. Сразу после
  знакомства помощник один раз предлагает экскурсию (кнопка «Покажи!»).
- Облачко над помощником: имя заголовком, кнопка «×» (закрыть), хвостик,
  цвет рамки — у каждого персонажа свой. Текст печатается по буквам, персонаж
  подпрыгивает; при «уменьшить движение» текст появляется сразу и без анимаций.
  Облачко скрывается само (не раньше чем через 6 с) и не мешает нажимать
  элементы под ним.
- Помощник отвечает на каждое действие: приветствие по времени суток со
  сводкой дня, добавление привычки (первая — отдельно), отметка любой клетки
  (сегодня и прошлые дни), снятие отметки (мягко), «осталось N», всё выполнено,
  первый закрытый день, новый рекорд, вехи серии 3/7/14/30/50/100 дней
  (с конфетти), напоминание, правка привычки, удаление. Реплики заранее
  написаны в стиле каждого персонажа, без ИИ и внешних сервисов (`src/companion.js`).
- Клик по персонажу — меню: «Спроси меня» (поле и кнопки частых вопросов;
  ~40 ответов по ключевым словам — как пользоваться трекером и советы по
  привычкам, `src/companion-qa.js`; вопрос никуда не отправляется и не
  сохраняется), «Экскурсия по трекеру» (6 шагов с подсветкой: форма, «Сегодня»,
  сетка, 🔔, ✏️, статистика; «Назад», «Далее», «Закрыть», Esc —
  `src/companion-tour.js`), «Сменить помощника», «Переименовать»
  (1–20 символов), «Выключить помощника». Выключенного помощника нет на
  странице; кнопка «Включить помощника» в шапке возвращает прежнего персонажа
  и имя.
- Совет дня: при первом открытии за день (по локальной дате) после приветствия
  помощник показывает один короткий совет (30 советов по кругу,
  `src/companion-tips.js`).
- Настройки помощника (персонаж, имя, включён ли, знакомство, предложена ли
  экскурсия, дата последнего совета) хранятся в браузере под ключом
  `habit-tracker:companion` (данные привычек — отдельно, в `habit-tracker:v1`,
  помощник их не меняет).
- Картинки персонажей — `public/companions/` (7 SVG и 7 WebP, Noto Emoji —
  Apache 2.0, Noto Emoji Animation — CC BY 4.0); подробности —
  `public/companions/ATTRIBUTION.md`, подпись — в подвале сайта.
- У анимированных эмодзи на карточках под анимацией лежит статичная картинка
  того же эмодзи (фон картинки), поэтому прозрачные кадры (💧 и др.) не
  оставляют плашку пустой.

## Структура

```text
habit-tracker/
├── AGENTS.md, CLAUDE.md   — правила для агентов
├── GOAL.md, STATUS.md     — цель и состояние проекта
├── index.html, src/       — приложение
├── tests/unit, tests/e2e  — тесты
├── plans/                 — планы итераций
├── reports/               — отчёты implement (реализация, тесты, запуск, аудит)
├── .claude/               — скиллы и роли для Claude Code
└── .agents/, .codex/      — исходная конфигурация курса для Codex
```

## Пайплайн разработки

1. Интервью (`interview-me`) → GOAL.md.
2. План итерации в Plan mode → `plans/NNN-*.md`.
3. Скилл `implement`: demo-implementer → demo-test-writer → demo-test-runner →
   demo-auditor, отчёты в `reports/NNN-*/NN/`.
4. Ручная приёмка, просмотр diff, коммит и push.
