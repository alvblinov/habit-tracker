## Ограничения и блокеры

- Тема проекта ещё не согласована с куратором.
- Напоминания работают только при открытой вкладке; опоздавшая больше чем на 5 мин проверка
  (фон, сон ПК) не досылает напоминание; повторное сохранение «Каждые N» сдвигает отсчёт — по плану.
- Две открытые вкладки с напоминаниями не проверялись (дубли системных уведомлений гасятся tag).
- NOTE аудита 003: закрытие формы редактирования при удалении привычки в другой вкладке тестом
  не покрыто; при открытии ✏️ у другой карточки несохранённый ввод первой формы пропадает.
- NOTE аудита 004: `getBestStreak` не ограничивает отметки датой «сегодня» (будущих отметок
  интерфейс не создаёт — на практике не влияет).
- NOTE аудита 005: сбой localStorage при чтении/записи темы тестом не покрыт (код защищён
  try/catch); токены тёмной темы продублированы для ручной и системной темы; в смешанных старых
  данных цвет по позиции может совпасть с уже сохранённым. Анимации эмодзи (WebP) весят ~3,8 МБ —
  грузятся лениво, только при отметке.
- Перерисовка через полночь в браузере не проверялась (ни тестами, ни вручную).
- NOTE аудита 001/02: после неудачной записи в localStorage вкладка перестаёт подхватывать
  изменения других вкладок (редкий случай). Не исправлялось.
- Агенты-исполнители не могут запускать e2e: их песочница запрещает подключения к localhost.
