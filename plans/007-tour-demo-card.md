# План 007 — Пример карточки в экскурсии

## Контекст

Без привычек шаги 2–5 экскурсии (AC-51) не находят цели: кнопки «Сегодня», сетка, 🔔 и ✏️
есть только на карточке. Страница затемняется, показывается текст «Когда добавишь привычку…»,
подсветки нет — пользователь принял это за сбой (20.10.2026). Решение пользователя (23.10.2026):
на время экскурсии показывать карточку-пример (`GOAL.md` → «Итерация 007», AC-55…AC-58).

Попутно при просмотре координатором (опубликованный сайт, 3 привычки, плавная прокрутка):
на шаге 6 цель `#stats-toggle` осталась выше окна (top ≈ −34px) — прокрутка к ней не дошла.
Прежний e2e экскурсии идёт только при `reducedMotion: 'reduce'` и это не ловит (AC-57).

Ветка `feature/tour-demo-card` (от `main` = 2e4b772); прогон → `reports/007-tour-demo-card/01/`.

## Логика

`src/companion-tour.js`:
- `DEMO_HABIT` — данные примера: `{ id: 'tour-demo', name: 'Пример: пить воду', emoji: '💧',
  days: все 7, createdAt, done: [] }` и чистая функция `demoHabit(today)` → копия с отметками
  за несколько прошлых дней (например, 4 из последних 6, без сегодня), даты — от переданного `today`.
- `needsDemo(state)` → `true`, если привычек нет.
- У шагов 2–5 `missingText` больше не нужен для пустого списка; поле оставить как запасной текст
  на случай, если цели всё же нет.

## Интерфейс (`src/main.js`, `src/style.css`)

- `startTour()`: если `needsDemo(state)` — добавить в `#habit-list` карточку `renderCard(demoHabit(today), …)`
  с `data-demo="true"`, `data-testid="tour-demo-card"` (не `habit-card`), атрибутом `inert`
  и `aria-hidden="true"`; скрыть подсказку пустого списка на время экскурсии.
  Над названием — метка «Пример» (`tour-demo-label`). Цвет — первый из палитры.
- `render()` во время открытой экскурсии (например, изменение из другой вкладки) сохраняет пример,
  пока привычек нет, и убирает его, если привычка появилась.
- `closeTour()` (Готово, Закрыть, Esc, выключение помощника) удаляет пример и возвращает
  обычный вид списка через `render()`.
- `tourTarget()` ищет цели шагов 2–5 сначала в настоящих карточках, затем в примере.
- Обработчики карточки не должны срабатывать для примера (`inert` + проверка `data-demo`);
  пример не участвует в сводке, кольце, статистике, напоминаниях и `commit`.
- AC-57: прокрутка к цели надёжно доходит до неё при плавной прокрутке (например, повторная
  проверка/подстановка позиции по окончании прокрутки, `scrollend` с запасным таймером,
  или прокрутка без smooth, если цель уже частично в окне); подсветка — по итоговой позиции.

## Тесты (demo-test-writer)

- `tests/unit/companion-tour.test.js` (новый или дополнить): `demoHabit(today)` — отметки только
  в прошлом, на переданных датах (смена месяца), `id`/имя примера; `needsDemo`.
- `tests/e2e/companion.spec.js`, блок «экскурсия»:
  - AC-55: без привычек — все 6 шагов `data-has-target="true"`, шаги 2–5 подсвечивают элементы
    внутри `tour-demo-card`, текст шагов — `step.text`. Прежний тест «без привычек: шаги про карточку
    объясняют без подсветки» описывает отменённое пользователем поведение — заменить на новый (решение
    пользователя 23.10.2026), остальные прежние тесты не менять.
  - AC-56: пример есть только во время экскурсии; клик по его «Сегодня» и клетке ничего не меняет;
    `habit-tracker:v1` прежний; сводка «0 из 0»; после Готово/Закрыть/Esc — примера нет, видна
    подсказка пустого списка; после reload примера нет.
  - AC-57: экскурсия с привычками и с пустым списком **без** reduced motion — цель каждого шага
    в окне и совпадает с подсветкой (с ожиданием окончания прокрутки), включая шаг 6.
  - AC-58: прежний набор unit и e2e проходит.

## Проверка

- `npm run test:unit`, `npm run test:e2e`, `npm run build`.
- Ручная: открыть сайт без привычек → меню помощника → «Экскурсия»: на шагах 2–5 подсвечивается
  карточка «Пример: пить воду»; нажать «Сегодня» на примере — ничего; закрыть — примера нет.
  Добавить привычку, пройти экскурсию — подсвечивается настоящая карточка, шаг 6 виден.
