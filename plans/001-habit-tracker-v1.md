# План 001 — Трекер привычек, первая версия

## Контекст

Домашнее задание курса «Вайбкодинг»: до 14.10 реализовать первую фичу и запушить её.
Требования согласованы в интервью и записаны в `GOAL.md` (AC-1…AC-9). Каркас
(Vite 8, Vitest 5, Playwright 1.64) закоммичен в `4886a03`; бизнес-кода и тестов пока нет.
Итог итерации — работающий трекер: добавить привычку с эмодзи, отметить сегодня,
серия «🔥 N», сетка 30 дней, удаление, «Сегодня выполнено X из Y», сохранение.

После утверждения план сохраняется в `plans/001-habit-tracker-v1.md`, затем запускается
скилл `implement` с прогоном в `reports/001-habit-tracker-v1/01/`.

## Архитектура

Логика — чистые функции без DOM и без `new Date()` внутри; «сегодня» передаётся параметром
строкой `YYYY-MM-DD`. Интерфейс перерисовывается целиком из состояния после каждого действия.

### Модель данных (localStorage, ключ `habit-tracker:v1`)

```js
{ version: 1, habits: [ { id, name, emoji, createdAt: 'YYYY-MM-DD', done: ['YYYY-MM-DD', ...] } ] }
```

### Файлы

| Файл | Содержание |
|---|---|
| `src/dates.js` | `toDateKey(date)` — локальная дата `YYYY-MM-DD` (через getFullYear/Month/Date, не toISOString); `addDays(key, n)` — сдвиг по календарю (через `new Date(y, m-1, d+n)`, корректно для смены месяца/года); `lastNDays(todayKey, n)` — массив из n ключей, последний = сегодня. |
| `src/habits.js` | Константы `EMOJIS` (12 шт.), `DEFAULT_EMOJI = '⭐'`, `MAX_NAME_LENGTH = 40`. Чистые функции, возвращают новое состояние: `createEmptyState()`, `normalizeName(raw)` (trim; `null` если пусто), `addHabit(state, {name, emoji}, {id, todayKey})` (невалидное имя → состояние без изменений; имя обрезается до 40; неизвестный эмодзи → ⭐), `toggleDay(state, id, dateKey, todayKey)` (будущая дата → без изменений), `removeHabit(state, id)`, `isDone(habit, key)`, `getStreak(habit, todayKey)` (AC-4: старт с сегодня, если отмечено, иначе со вчера; считать назад до первого пропуска), `getTodaySummary(state, todayKey)` → `{done, total}`. |
| `src/storage.js` | `STORAGE_KEY`, `loadState(storage)` — читает и проверяет форму; при отсутствии/битом JSON/неверной структуре → пустое состояние, отбрасывает некорректные привычки и даты; `saveState(storage, state)` — пишет только свой ключ, ошибки записи не роняют страницу. `storage` передаётся параметром (в тестах — заглушка). |
| `src/main.js` | Связывает DOM с логикой: `today = toDateKey(new Date())` на каждом рендере; `render()` строит форму, сводку, список/пустое состояние; обработчики → функция из `habits.js` → `saveState` → `render()`. Пересчёт при `focus`/`visibilitychange` (если вкладка открыта через полночь). Удаление — `window.confirm('Удалить привычку «…»?')`. id — `crypto.randomUUID()`. Весь пользовательский текст — через `textContent`. |
| `index.html` | Статическая разметка: заголовок, форма (input `maxlength=40`, выбор эмодзи — группа радиокнопок-иконок, кнопка «Добавить»), сводка, контейнер списка. |
| `src/style.css` | Карточки привычек, кнопка «сегодня», сетка 30 клеток (CSS grid, 10×3 на узком экране / 15×2 на широком), выделение отмеченных и сегодняшней клетки, адаптив от 320px. |

### Интерфейс карточки привычки

`эмодзи + название` · `🔥 N дней подряд` (с правильным склонением: день/дня/дней) ·
кнопка «Сегодня ✓» (aria-pressed) · сетка 30 кнопок-дней (aria-pressed, `title`/`aria-label`
с датой, слева старые → справа сегодня) · кнопка «Удалить».

Для тестов — стабильные `data-testid`: `habit-name-input`, `emoji-option`, `add-habit`,
`habit-card`, `habit-streak`, `toggle-today`, `day-cell` (+ `data-date`), `delete-habit`,
`today-summary`, `empty-state`.

## Тесты (пишет demo-test-writer)

- `tests/unit/dates.test.js` — локальный ключ даты, смена месяца/года, високосный 29.02, `lastNDays(…, 30)`.
- `tests/unit/habits.test.js` — AC-1/2 (валидация, trim, 40 символов, дубликаты, эмодзи по умолчанию),
  AC-3 (переключение), AC-4 (серия: сегодня отмечено / не отмечено, пропуск дня, через границу месяца),
  AC-5 (будущая дата игнорируется), AC-6, AC-7.
- `tests/unit/storage.test.js` — отсутствие данных, битый JSON, чужие ключи не трогаются, круговой save→load.
- `tests/e2e/habits.spec.js` — Playwright с `page.clock.setFixedTime(...)` на фиксированной дате:
  добавление, отметка, сетка (клик по прошлому дню меняет серию), удаление с confirm (accept/dismiss),
  сводка, пустое состояние, сохранение после `page.reload()` (AC-8), название с `<b>` выводится как текст.

## Не входит

Редактирование, расписание, лучшая серия, статистика, экспорт, новые зависимости.

## Проверка

1. `npm run test:unit` — все unit-тесты проходят, тесты реально обнаружены.
2. `npm run test:e2e` — браузерные тесты проходят в Chromium.
3. `npm run build` — сборка без ошибок.
4. Аудит demo-auditor → `reports/001-habit-tracker-v1/01/audit.md` со статусом PASS.
5. Ручная приёмка в браузере (`npm run dev`): добавить 2 привычки с разными эмодзи → отметить одну
   сегодня → сводка «1 из 2» → кликнуть 2 прошлых дня в сетке → «🔥 3» → обновить страницу →
   всё на месте → удалить привычку (сначала «Отмена», потом «ОК») → телефонная ширина в DevTools.
6. После приёмки — обновить STATUS.md, коммит и push (вручную, с подтверждения пользователя).
