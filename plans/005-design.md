# План 005 — Визуал и дизайн

## Контекст

Итерации 001–004 приняты, сайт опубликован на GitHub Pages (автопубликация с unit + e2e).
Пользователь выбрал по референсам (Habitify, Tick it, HabitKit, Streaks) направление
«мягкий минимализм» + кольцо прогресса дня, цвета привычек и тёмную тему с ручным
переключателем (интервью 14.10.2026; `GOAL.md` → «Итерация 005», AC-32…AC-36).
Цель — аккуратный современный вид без изменения поведения: тексты, `data-testid` и логика остаются,
все прежние 359 тестов должны пройти без правок ожиданий.

После утверждения: план → `plans/005-design.md`, ветка `feature/design`,
прогон `implement` → `reports/005-design/01/`, PR в `main` (CI прогонит unit + e2e).

## Модель данных

- У привычки поле `color` — ключ палитры: `teal | purple | coral | pink | blue | green | amber | gray`.
- `addHabit` назначает первый ключ палитры, не занятый другими привычками; если заняты все — по кругу
  (`index % 8`).
- `loadState`/`sanitizeHabit`: нет/битый `color` → ключ по позиции привычки в списке (`PALETTE[i % 8]`).
- `updateHabit(state, id, { name, emoji, days, color })` — `color` через `normalizeColor`; неизменённые
  значения → тот же объект. Ключ хранилища и `version: 1` не меняются.

## Логика (чистые функции)

| Файл | Что |
|---|---|
| `src/colors.js` (новый) | `PALETTE` (8 ключей по порядку из GOAL), `COLOR_LABELS` (рус. названия для aria-label: «бирюзовый»…), `normalizeColor(raw)` → ключ или `null`, `nextFreeColor(habits)`. |

| `src/storage.js` | `sanitizeHabit(raw, index)` → `color: normalizeColor(raw.color) ?? PALETTE[index % 8]`. |

## Оформление (`src/style.css`, `index.html`, `src/main.js`)

- **Токены темы** на `:root` (светлая: тёплый фон `#FBFAF7`-подобный, белые карточки, мягкие границы)
  и `:root[data-theme="dark"]` (тёмная). Без ручного выбора — `@media (prefers-color-scheme: dark)`
  для `:root:not([data-theme="light"])`. Все цвета интерфейса — через переменные.
- **Цвета привычек**: CSS-правила `[data-color="teal"] { --habit: …; --habit-soft: …; --habit-strong: … }`
  для 8 ключей в обеих темах (контраст текста на `--habit-soft` ≥ AA). Карточка получает
  `data-color` (значение только из палитры, не из пользовательского ввода).
  Цвет применяется: плашка под эмодзи (`--habit-soft`), кнопка `toggle-today` в отмеченном состоянии
  (`--habit`), выполненные клетки сетки (`.day-cell.is-done`), строка/полоска статистики (`stats-row`).
  Выходные клетки (`is-off`) и сегодняшняя клетка остаются визуально отличимыми (прежние e2e
  сравнивают стили — отмеченная ≠ неотмеченная, выходная ≠ рабочая).
- **Карточки**: скругление 16–20px, мягкая тень/граница, отступы; кнопка «сегодня» — круглая/«пилюля»
  в цвете привычки с прежним текстом «Сегодня» / «Сегодня ✓»; клетки сетки — скруглённые квадраты;
  анимация отметки (короткий scale/transition, отключается при `prefers-reduced-motion`).
- **Форма ✏️**: под эмодзи — 8 цветных кружков `edit-color-option` (radio, `value` = ключ,
  `aria-label` = название цвета), отмечен текущий цвет.
- **Кольцо прогресса** (шапка, рядом с заголовком): SVG-кольцо `progress-ring`
  (`data-done`, `data-total`, `data-complete="true|false"`), в центре `progress-ring-label` «X/Y»;
  доля = X/Y (Y = 0 → пустое кольцо «0/0»); при X = Y > 0 — заполнено, цвет «успех» (зелёный).
  Прежний `today-summary` с текстом «Сегодня выполнено X из Y» остаётся рядом.
- **Переключатель темы**: кнопка `theme-toggle` в шапке, ☀️/🌙, `aria-label`
  «Включить тёмную тему» / «Включить светлую тему», `aria-pressed` = тёмная.
  Тема ставится атрибутом `data-theme` на `<html>`; чтобы не было вспышки при загрузке —
  небольшой inline-скрипт в `<head>` `index.html`, читающий `habit-tracker:theme` (try/catch).
  Без ручного выбора атрибут не ставится — работает системная тема.
- Шрифт — системный стек (`system-ui, -apple-system, "Segoe UI", Roboto, …`), без загрузки из сети.
- Все существующие тексты и `data-testid` сохраняются; пользовательский текст — через `textContent`.

# Дополнение (прогон 02): «живые» эмодзи Noto и фон с пастельными пятнами

## Контекст

Прогон 01 прошёл (аудит PASS). После просмотра пользователь попросил более красивые эмодзи и фон.
По сравнению 7 наборов он выбрал «живые» эмодзи Google Noto (анимация при отметке) и фон
с пастельными пятнами (14.10.2026). Требования — `GOAL.md`, «Дополнение к итерации 005», AC-37…AC-40;
правило об эмодзи в `AGENTS.md` обновлено. Ассеты уже скачаны координатором в `public/emoji/`
(12 статичных SVG, 9 анимированных WebP 512px, `ATTRIBUTION.md`; SVG проверены — без скриптов
и внешних загрузок). Прогон: `reports/005-design/02/`.

## Логика

- `src/emoji-assets.js` (новый, чистый): `emojiCode(char)` → имя файла (код точек в hex через `_`,
  нижний регистр: `💧` → `1f4a7`, `✍️` → `270d_fe0f`), `staticEmojiUrl(char)` → `emoji/<код>.svg`,
  `animatedEmojiUrl(char)` → `emoji/<код>.webp` или `null` для 🏃 🧘 💊 (`HAS_ANIMATION` — набор кодов).
  Пути относительные (`base: './'`), Vite копирует `public/` в `dist/`.

## Интерфейс (`src/main.js`, `src/style.css`, `index.html`)

- Общий помощник `renderEmoji(char, { animated })` → `<img alt="" aria-hidden="true">` + скрытый
  (`visually-hidden`) текст с символом. Так `textContent` элементов (`habit-emoji`, `emoji-option`,
  `edit-emoji-option`, эмодзи в статистике) остаётся прежним символом — все прежние `toHaveText('📚')`
  и `data-emoji` проходят без изменений; доступное имя — символ.
- Применить в: форме добавления (12 вариантов), форме ✏️, плашке карточки, строке статистики.
- «Оживление»: при переключении отметки в состояние «выполнено» (кнопка `toggle-today` или клетка
  сегодняшнего дня) запоминается `{ habitId, until: Date.now() + 2000 }` в памяти модуля; `renderCard`
  для этой привычки до `until` показывает `animatedEmojiUrl` (если есть), иначе статичную картинку
  с CSS-классом `is-bounce`; затем `setTimeout` перерисовывает обратно. Атрибут
  `data-animating="true"` на `habit-emoji` на время эффекта (для тестов). Снятие отметки и отметка
  прошлых дней эффекта не дают. При `matchMedia('(prefers-reduced-motion: reduce)')` — без эффекта.
  WebP грузится только при первом показе (обычный `<img src>`), далее из кеша браузера.
- Системные уведомления не меняются (символ в заголовке).
- Подвал `<footer class="app-footer" data-testid="emoji-credit">`: «Эмодзи: Google Noto (CC BY 4.0,
  Apache 2.0)» со ссылкой на `https://googlefonts.github.io/noto-emoji-animation/`
  (`rel="noopener"`, `target="_blank"`).
- Фон: 3 размытых пастельных пятна (бирюзовый, фиолетовый, коралловый) — фиксированный псевдоэлемент
  `body::before` с `radial-gradient`, `pointer-events: none`, `z-index: -1`; в тёмной теме — приглушённые
  (низкая непрозрачность). Карточки остаются непрозрачными (текст на них — прежний контраст);
  основной фон страницы под текстом вне карточек — контраст ≥ 4.5 сохраняется.
- README: раздел «Оформление» — эмодзи Noto, оживление, авторство.
