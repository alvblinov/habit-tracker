# План 002 — Напоминания

## Контекст

Пользователь хочет, чтобы трекер сам напоминал о привычке («разминка каждый час»).
Требования согласованы в интервью 13.10.2026 и записаны в `GOAL.md`, раздел
«Итерация 002 — напоминания», AC-10…AC-16. Рамки: без сервера, поэтому напоминания
работают только пока вкладка открыта; пропущенные не досылаются.
Базовая версия — `main` = `8ba7c2b` (итерация 001 принята).

После утверждения: план → `plans/002-reminders.md`, прогон `implement` → `reports/002-reminders/01/`,
работа в ветке `feature/reminders`, затем PR в `main`.

## Модель данных

К привычке добавляется поле `reminder` (ключ хранилища и `version: 1` не меняются —
старые данные без поля читаются как `reminder: null`, AC-15):

```js
reminder: null
  | { mode: 'interval', intervalMin: 30 | 60 | 120 | 180, start: 'HH:MM', end: 'HH:MM', anchor: <ms epoch> }
  | { mode: 'times', times: ['HH:MM', ...] }   // 1–5, без повторов, отсортированы
```

`anchor` — момент включения/сохранения напоминания («отсчёт от включения»).
Активные часы: `start < end` в пределах одних суток (по умолчанию 09:00–21:00).
